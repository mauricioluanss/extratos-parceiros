# Automação de Extratos de Repasses

## Importante

Este repositório contém apenas os scripts responsáveis pela manipulação dos dados.
Os **arquivos de entrada** e **regras de negócio da empresa** não estão incluídos.

## Contexto

Desenvolvi este script para resolver um tarefa chata: a emissão mensal dos extratos de repasses para os parceiros da empresa.
Antes da automação, o processo era totalmente manual, repetitivo e demorado, além de estar sujeito a erros, já que cada extrato precisava ser feito individualmente.
Eu perdia um tempão nessa parada, e ainda errava algumas vezes...

## Funcionamento

- O script recebe **2 arquivos de entrada** como fonte de dados
- A partir deles, processa todas as informações necessárias
- No final, gera um **.xlsx** contendo os valores de repasses organizados para cada parceiro. Na forma como o Financeiro espera

## Resultados

- Eliminação de erros manuais no cálculo e na geração dos extratos
- Redução significativa do tempo gasto na tarefa
